# Kennungssuche

Kleine Windows-Anwendung zur Suche von Kennungen aus einer separat pflegbaren CSV-Datei.

## Start

`Kennungssuche.lnk` doppelt anklicken.

Falls Windows die Verknüpfung blockiert, kann sie mit einem Rechtsklick und **Öffnen** gestartet werden.


## Daten pflegen

Die Datei `kennungen.csv` mit Excel, LibreOffice oder einem Texteditor öffnen. Eine Zeile besteht aus:

```text
Kennung;Vorname;Nachname
BB-1001;Paul;Neumann
```

Die Spaltennamen und das Semikolon als Trennzeichen beibehalten. Danach in der Anwendung **Daten neu laden** klicken oder die Anwendung neu starten.

Die enthaltenen Einträge sind ausschließlich anonyme Beispieldaten.
